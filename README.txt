BrightSteps Class 3 — browser preview bundle

To view locally:
1. Unzip this archive.
2. Open a terminal in the extracted directory.
3. Run: python3 -m http.server 8000
4. Open http://localhost:8000 in a browser.

The core lesson and quiz content is bundled with the preview. This is a browser preview bundle, not an Android APK. To make an installable Android app, build an APK through the BrightSteps project Dashboard.
